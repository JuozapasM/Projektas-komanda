# Auksinis Protas

Rezervacijų sistema protmūšio vakarams: keturi stalai, po keturias vietas, individualios dalyvių paskyros ir administratoriaus veiksmų istorija.

## Paleidimas

```bash
npm install
cp .env.example .env.local
npm run dev
```

Demonstracinėje versijoje registracija ir rezervacijos veikia naršyklėje. Supabase schema paruošta faile `supabase/migrations/202609140001_initial_schema.sql`.
